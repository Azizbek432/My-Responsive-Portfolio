🚀 My Responsive Portfolio
This is my professional personal portfolio website, designed to showcase my skills, projects, and experience. Built with a focus on modern UI/UX, smooth animations, and full responsiveness across all devices.
🔗 Live Demo: View my Portfolio on Vercel

🌟 KEY FEATURES:
- Modern UI/UX: Sleek, dark-themed professional design.
- Fully Responsive: Optimized for Mobile, Tablet, and Desktop screens.
- Interactive Elements: Smooth scrolling and hover effects.
- Resume Integration: Direct link to view/download my professional CV.
- Contact Form: Integrated section for networking and inquiries.

🛠️ TECH STACK:
- HTML5: Semantic structure for better SEO.
- CSS3: Custom properties, Flexbox, Grid, and Keyframe animations.
- JavaScript: Dynamic interactions and scroll logic.
- Deployment: Hosted on Vercel for high performance.

📂 REPOSITORY STRUCTURE:
- /css: Custom stylesheets for layout and design.
- /js: Logic for responsiveness and interactivity.
- /img: Optimized assets and profile images.
- /pdf: Professional resume and certifications.
